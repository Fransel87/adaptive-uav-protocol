# Адаптивный протокол обмена данными для БПЛА

Программная модель адаптивного протокола для НИРС на тему:
«Разработка и исследование адаптивного протокола обмена данными
для БПЛА с дифференцированной обработкой трафика в условиях
нестабильного канала связи».

## Состав проекта

- **DroneClient/** — симулятор БПЛА (генерация телеметрии, фото, адаптация)
- **GroundStation/** — наземная станция (эмуляция канала, сбор метрик)
- **common/** — общие заголовочные файлы протокола (protocol.h)

## Сборка и запуск

Требования: Qt 6+ с модулями Core, Network, Widgets.

1. Во вкладке слева "Projects"/"Проекты" в разделе "Build Settings"/"Настройки сборки" снять галочку "Shadow build"/"Теневая сборка"
2. Открыть DroneClient.pro в QtCreator, собрать, запустить
3. Открыть GroundStation.pro в QtCreator, собрать, запустить
4. В окне дрона нажать «Подключиться»
5. В окне станции нажать «Старт»
6. Для автоматического сценария нажать «Авторежим»
